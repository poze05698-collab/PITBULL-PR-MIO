# Pitbull Prêmio

PWA web-first do projeto Pitbull Prêmio.

## Stack inicial

- React
- TypeScript
- Vite
- vite-plugin-pwa
- Supabase (backend, próxima etapa)

## Regras

- Não apagar dados do Supabase.
- Saldo nunca é alterado diretamente pelo navegador.
- Créditos de pontos passam pelo backend e pelo ledger.
- Eventos de provedores precisam ser idempotentes.
- Segredos e chaves privadas ficam somente no backend.

## Desenvolvimento

```bash
npm install
npm run dev
```
